# wpython
Привет, это мой проект wpython (windows python) он служит запуском программ для python, но он сделан для windows

расписка:

главная папка - папка в которой, scripts - папка где находятся скрипты и название лучше не менять, mainpy.py - исходный файл скрипта и название лучше не менять, program.bat - главный запускаемый файл (cmd файл для windows)
